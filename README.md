# CampusPe Landing Page

Pixel-focused responsive recreation of the supplied CampusPe landing-page reference, built with **Next.js + React + Tailwind CSS**.

## Features
- Responsive desktop/tablet/mobile layouts
- Reusable React components
- Matching blue/white/lavender visual language, rounded cards and soft shadows
- Sticky responsive navigation + mobile menu
- Interactive CTA hover/focus/active states
- Hero search interaction and subtle 3D card hover
- Opportunity feed tabs
- Resume upload/dropzone interaction
- Waitlist modal with form state
- App preview carousel controls
- Smooth anchor navigation

## Run locally

```bash
npm install
npm run dev
```

Open http://localhost:3000.

## Production build

```bash
npm run build
npm start
```

## Deployment

The app is ready for Vercel/Netlify deployment. For Vercel:

```bash
npm i -g vercel
vercel
```

Then follow the CLI prompts and connect the project to the GitHub repository.

## Source reference
The supplied one-page Assignment PDF was used as the visual/content reference. The implementation intentionally uses recreated UI components rather than copying image assets.
